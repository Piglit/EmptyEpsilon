Files in this directory are used to create a star-wars-fan-mod.

When EE looks up a resouce, it looks in this directory (and it's subdirectoris) first, so if files with the same name occure in some other directory, those in this directory are preferred.
You can still import/require vanilla-scripts from lua files in this directory.

Important top-level files (replace vanilla files):
* shipTemplates.lua
* factionInfo.lua
* model_data.lua
* science_db.lua
